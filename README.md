# Rebecca L. Jones — Professional Website

A responsive static portfolio website for GitHub Pages. No build tools or dependencies are required.

## Publish at `https://drbexjones.github.io/`

1. Sign in to GitHub as **drbexjones**.
2. Create a **public** repository named **`drbexjones.github.io`** (exact spelling).
3. Upload the contents of this folder to the repository **root** (not a nested folder). Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
4. Open **Settings → Pages → Build and deployment**. Choose **Deploy from a branch**, branch **main**, folder **/(root)**, and save.
5. Once GitHub publishes it, visit `https://drbexjones.github.io/`.

If you already have a repository named `drbexjones.github.io`, **do not overwrite it without backing it up**. You can alternatively publish this site from a different repository, e.g. `professional-website`, at `https://drbexjones.github.io/professional-website/`.

## Edit content
